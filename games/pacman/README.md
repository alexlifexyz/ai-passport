### 📖 Overview

The iconic arcade maze chase! Eat all dots across the neon labyrinth, grab Power Pellets to turn the tables, and chomp the ghosts!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Turn UP direction |
| **DOWN** | Turn DOWN direction |
| **OK (Short)** | Turn clockwise / Speed dash |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
