### 📖 游戏简介

经典的黄色小精灵迷宫追逐战！在霓虹迷宫中吃遍所有能量豆，吃到能量大力丸时反客为主，把调皮小幽灵通通吃掉！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 向上转弯方向 |
| **DOWN (短按)** | 向下转弯方向 |
| **OK (短按)** | 顺时针转向 / 氮气加速 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |
