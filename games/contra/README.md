### 📖 Overview

Iconic hardcore run-and-gun combat! Dodge barrages, pick up weapon upgrades, blast enemy turrets, and destroy the alien heart!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Aim upward / Flip jump |
| **DOWN** | Prone duck (dodge bullets) |
| **OK (Short)** | Rapid gunfire |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
