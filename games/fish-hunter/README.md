### 📖 Overview

Underwater survival of the fittest! Start as a tiny fish, eat smaller prey to evolve, and evade menacing great white sharks!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Swim upward |
| **DOWN** | Dive downward |
| **OK (Short)** | Sprint bite |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
