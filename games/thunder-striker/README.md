### 📖 Overview

Arcade vertical shmup action! Pilot high-tech fighters through dense enemy bullet storms, upgrade your spreads, and unleash devastating screen bombs!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Move forward / climb |
| **DOWN** | Move backward / retreat |
| **OK (Short)** | Cannon burst fire |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
