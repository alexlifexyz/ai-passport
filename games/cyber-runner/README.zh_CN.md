### 📖 游戏简介

化身赛博信使在霓虹闪烁的未来都市屋脊穿梭，掌握精准二段跳、蹬墙反弹与光刃斩击，突破激光与重重陷阱！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 跳跃 / 空中二段跳 / 接触墙壁触发蹬墙反跳 |
| **DOWN (短按)** | 贴地滑铲，穿过低矮障碍区 |
| **OK (短按)** | 挥动光刃斩击，击破前方的无人机与障碍箱 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---
