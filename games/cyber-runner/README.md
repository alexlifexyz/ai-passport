### 📖 Overview

Run across neon skyscraper rooftops as an agile cyber ninja. Master double jumps, wall-kicks, and blade slashes through intense obstacle courses!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Jump / Air double-jump / Wall-kick against surfaces |
| **DOWN** | Low slide underneath high barriers |
| **OK (Short)** | Katana blade slash to destroy drone obstacles |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
