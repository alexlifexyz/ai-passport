### 📖 游戏简介

重现掌心里的怀旧电子宠物！实时饥饿度与心情值模拟，定时喂食、清理便便、玩抓飞碟小游戏，见证可爱宠物的成长蜕变！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP / DOWN** | 在互动菜单栏中切换图标（喂食/玩耍/洗澡/看病） |
| **OK (短按)** | 确认执行当前选中的抚育指令 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---

### 📦 源码与运行方式

- **源码位置**：`分支: demo/tamagezi`
- **固件合集启动**：刷入当前仓库 [Alex Arcade 掌机固件](../../README.zh_CN.md) 后，在开机菜单中选择 **Tamagezi Virtual Pet** 即可进入。
- **返回游戏大厅**：点击返回 [🎮 游戏中心展厅目录](../../README.zh_CN.md)。
