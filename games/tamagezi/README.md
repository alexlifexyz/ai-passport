### 📖 Overview

Nostalgic handheld virtual pet simulation! Feed, clean, play mini-games, and watch your companion evolve over time!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP / DOWN** | Cycle interaction icons (feed/play/clean/medicine) |
| **OK (Short)** | Confirm selected pet care action |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |

---

### 📦 Source & Flashing

- **Source Code**: `Branch: demo/tamagezi`
- **Play via Arcade**: Flash the [Alex Arcade Full Firmware](../../README.md), then choose **Tamagezi Virtual Pet** from the boot menu.
