### 📖 游戏简介

超萌像素小白兔常驻屏幕！拥有眨眼、打哈欠、吃多汁胡萝卜、蹦跳巡游等多种生动动画，是办公桌上最暖心的灵动陪伴。

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **OK (短按)** | 给小兔子投喂胡萝卜，触发开心咀嚼动画 |
| **UP / DOWN** | 抚摸兔子触发蹦跳欢呼 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---

### 📦 源码与运行方式

- **源码位置**：`分支: demo/white-rabbit-pet`
- **固件合集启动**：刷入当前仓库 [Alex Arcade 掌机固件](../../README.zh_CN.md) 后，在开机菜单中选择 **White Rabbit Mascot** 即可进入。
- **返回游戏大厅**：点击返回 [🎮 游戏中心展厅目录](../../README.zh_CN.md)。
