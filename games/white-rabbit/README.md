### 📖 Overview

An adorable fluffy white rabbit for your desk! Packed with lively animations including chewing carrots, hopping, blinking, and napping.

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **OK (Short)** | Feed delicious carrot to trigger joyful chewing |
| **UP / DOWN** | Pet bunny to trigger excited hops |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
