### 📖 Overview

Retro island platforming adventure! Collect tropical fruits to sustain your stamina bar, throw stone axes at wild creatures, and conquer stages!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Jump over rocks, firepits, and chasms |
| **DOWN** | Run forward |
| **OK (Short)** | Throw spinning stone axe |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
