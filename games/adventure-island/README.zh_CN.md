### 📖 游戏简介

经典横版海岛冒险！沿途狂吃香蕉草莓维持饥饿体力槽，投掷小石斧击溃野兽怪物，拾取隐藏彩蛋挑战高分！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 高桥跳跃（跃过落石、篝火与深坑） |
| **DOWN (短按)** | 往前冲锋迈步 |
| **OK (短按)** | 投掷旋转石斧远程杀敌 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---

### 📦 源码与运行方式

- **源码位置**：`main/demo_adventure.c, main/adventure_logic.c`
- **固件合集启动**：刷入当前仓库 [Alex Arcade 掌机固件](../../README.zh_CN.md) 后，在开机菜单中选择 **Adventure Island** 即可进入。
- **返回游戏大厅**：点击返回 [🎮 游戏中心展厅目录](../../README.zh_CN.md)。
