### 📖 游戏简介

风靡半个世纪的益智神作！在下落的七种方块中寻找最佳拼接角度，层层消行获取高分，挑战手脑极限！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 顺时针旋转方块 |
| **DOWN (短按)** | 加速下落（软降） |
| **OK (短按)** | 左右变位 / 瞬间硬降到底 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---
