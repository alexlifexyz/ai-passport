### 📖 Overview

Faithfully recreated retro NES tank combat. Defend the eagle headquarters, tactically maneuver around brick walls, and destroy enemy armored divisions!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Steer clockwise and advance |
| **DOWN** | Steer counter-clockwise and advance |
| **OK (Short)** | Fire tank cannon shell |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
