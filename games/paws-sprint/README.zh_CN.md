### 📖 游戏简介

操控短腿柯基、软萌折耳猫或圆滚小法斗，在 3 条跑道上闪转腾挪、起跳越障、收集零食金币并体验旋转起步！色彩明快，节奏轻快解压，治愈力满分。

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (上键)** | 向上变道（精准对齐中线，不跑偏） |
| **DOWN (下键)** | 向下变道（精准对齐中线，不跑偏） |
| **OK (短按)** | 角色轻盈起跳，跃过跨栏与泥坑障碍 |
| **OK (长按 1.5s)** | 结束当前对局并安全返回主菜单 |
