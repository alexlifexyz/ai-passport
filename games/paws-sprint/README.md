### 📖 Overview

Dash across 3 lanes as a bouncing Corgi, Scottish Fold, or Frenchie! Leap over hurdles, grab treats and golden coins, and sprint with joyful spin starts! Bright, colorful, and delightfully relaxing.

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Shift up a lane (auto centers cleanly) |
| **DOWN** | Shift down a lane (auto centers cleanly) |
| **OK (Short)** | Jump cleanly over hurdles and mud puddles |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
