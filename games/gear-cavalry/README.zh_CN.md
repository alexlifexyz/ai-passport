### 📖 游戏简介

驾驶重工业蒸汽动力突进装甲战车，积聚过载压力开启蒸汽暴冲，以排山倒海之势粉碎机械路障与钢铁敌军！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 装甲战车向上换道 |
| **DOWN (短按)** | 装甲战车向下换道 |
| **OK (短按)** | 消耗蒸汽释放【过载冲锋】，瞬间撞毁沿途障碍 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---

### 📦 源码与运行方式

- **源码位置**：`main/demo_geartrooper.c, main/geartrooper_logic.c`
