### 📖 Overview

Command a steam-driven mechanized cavalry! Accumulate boiler pressure to unleash blistering steam overdrive bursts and smash mechanical defenses!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Shift vehicle to upper lane |
| **DOWN** | Shift vehicle to lower lane |
| **OK (Short)** | Steam Overdrive charge (invulnerable dash) |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
