### 📖 游戏简介

沉浸式极简修禅工具！细腻的木槌物理敲击动效，每次敲击伴随清脆真实的木鱼声波与【功德 +1】浮动徽章，瞬间抚平焦虑。

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **OK (短按)** | 敲击木鱼，发声并触发【功德 +1】动效 |
| **UP / DOWN** | 切换音量大小或自动/手动诵念模式 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---

### 📦 源码与运行方式

- **源码位置**：`分支: demo/coloros-muyu`
- **固件合集启动**：刷入当前仓库 [Alex Arcade 掌机固件](../../README.zh_CN.md) 后，在开机菜单中选择 **ColorOS Wooden Fish** 即可进入。
- **返回游戏大厅**：点击返回 [🎮 游戏中心展厅目录](../../README.zh_CN.md)。
