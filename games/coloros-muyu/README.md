### 📖 Overview

Immersive meditation tool! Features physical striker animations, authentic acoustic wood tone synthesis, and floating merit badges.

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **OK (Short)** | Strike wooden fish, play sound, accumulate merits |
| **UP / DOWN** | Adjust audio volume or toggle auto mode |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
