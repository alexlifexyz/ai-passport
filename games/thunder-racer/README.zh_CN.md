### 📖 游戏简介

俯视角超速高速公路挑战！在密集车流中风骚超车，捡拾氮气能量瓶开启超音速爆发，挑战心跳与极限反应力！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 向左车道快速切道 |
| **DOWN (短按)** | 向右车道快速切道 |
| **OK (短按)** | 消耗氮气释放【超速爆发冲刺】 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---

### 📦 源码与运行方式

- **源码位置**：`main/demo_thunderracer.c, main/thunderracer_logic.c`
