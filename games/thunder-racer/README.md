### 📖 Overview

Overhead highway racing! Weave past dense traffic, collect nitro energy pickups to trigger supercharged boosts, and test your reaction limits!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Steer left lane |
| **DOWN** | Steer right lane |
| **OK (Short)** | Trigger Nitro Speed Boost |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
