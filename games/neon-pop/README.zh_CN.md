### 📖 游戏简介

专为掌机优化的 40FPS 高帧率矢量消除游戏！极简三键完成光标定位与宝石交换，触发绚烂霓虹粒子爆破与多重连锁！

---

### 🎮 操作指南

| 按键 | 动作效果 |
| :--- | :--- |
| **UP (短按)** | 选中光标向上移动 |
| **DOWN (短按)** | 选中光标向下移动 |
| **OK (短按)** | 选中宝石并与相邻宝石交换触发消除 |
| **OK (长按 1.5s)** | 退出并返回主菜单 |

---
