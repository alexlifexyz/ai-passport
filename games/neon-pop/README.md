### 📖 Overview

High-framerate 40FPS vector match-3 puzzle! Intuitive 3-button controls for cursor navigation and gemstone swapping, triggering dazzling particle fireworks!

---

### 🎮 Controls

| Button | In-Game Action |
| :--- | :--- |
| **UP** | Move cursor up |
| **DOWN** | Move cursor down |
| **OK (Short)** | Select gem and swap with neighbor to match |
| **OK (Long 1.5s)** | Exit and return to main launcher menu |
